다른 컴퓨터에서 실행하는 방법

1. GitHub에서 app 브랜치 다운로드
- 저장소 주소: https://github.com/nowonjong/Moble
- Branches에서 app 브랜치를 선택한 후 다운로드합니다.
- main 브랜치가 아닌 app 브랜치를 받아야 합니다.

2. 개발 환경 준비
- Visual Studio 2022를 설치합니다.
- Visual Studio Installer에서 ".NET 데스크톱 개발" 워크로드를 설치합니다.
- 이 프로젝트는 .NET 6 Windows Forms를 사용합니다.

3. 프로젝트 실행
- 다운로드한 폴더에서 sushi\sushi.sln 파일을 Visual Studio로 엽니다.
- 솔루션을 빌드한 후 실행합니다.
- bin, obj, .vs 폴더는 Visual Studio가 빌드할 때 자동으로 생성하므로 없어도 됩니다.

4. 관리자 컴퓨터 IP 설정
- sushi\sushi\TcpClient.cs 파일을 엽니다.
- ServerIp 값을 관리자 프로그램이 실행되는 컴퓨터의 IPv4 주소로 변경합니다.

예시:
public static string ServerIp = "192.168.0.62";
public const int ServerPort = 9000;

- 관리자 컴퓨터의 IP가 바뀌면 ServerIp도 다시 수정해야 합니다.

5. TCP 연결 조건
- 관리자 프로그램을 먼저 실행하고 TCP 서버를 시작합니다.
- 관리자 서버는 9000번 포트를 사용해야 합니다.
- 앱 컴퓨터와 관리자 컴퓨터는 같은 네트워크에 연결되어 있어야 합니다.
- 관리자 컴퓨터의 Windows 방화벽에서 9000번 포트 연결이 허용되어야 합니다.

6. 실행 확인
- 관리자 서버를 실행한 상태에서 앱을 실행합니다.
- 회원가입, 로그인, 메뉴 조회, 주문 전송이 정상적으로 되는지 확인합니다.
- TCP 연결이 실패하면 관리자 IP, 포트 번호, 같은 네트워크 연결 여부와 방화벽을 확인합니다.

참고
- MenuImages 폴더와 susi_menu.csv는 프로젝트에 포함되어 있으며 빌드할 때 실행 폴더로 자동 복사됩니다.
- 관리자 서버가 실행되지 않았거나 IP가 잘못되면 회원가입, 로그인, 메뉴 조회와 주문 전송 기능이 작동하지 않습니다.
