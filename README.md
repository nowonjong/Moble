# 📌 프로젝트 소개

초밥 매장의 실제 운영 환경을 가정하여  
**관리자, 키오스크, 모바일 앱, 웨이팅 프로그램**을 하나의 시스템으로 연동한 프로젝트입니다.

고객의 주문과 결제부터 모바일 주문, 대기 고객 관리,  
관리자의 주문 처리 및 회원·포인트·매출 관리까지  
매장에서 발생하는 주요 업무 흐름을 구현했습니다.

```text
                    고객
                     │
          ┌──────────┼──────────┐
          │          │          │
          ▼          ▼          ▼
       키오스크       앱       웨이팅
          │          │          │
          │          │          │
          └──────┬───┘          │
                 │              │
             TCP/IP             │
              JSON              │
                 │              │
                 ▼              │
         ┌───────────────┐      │
         │ 관리자 시스템 │      │
         │   TCP Server  │      │
         └───────┬───────┘      │
                 │              │
                 ▼              ▼
          주문 / 회원 / 포인트 / 매출
```

각 프로그램은 담당자별 브랜치에서 개발하고  
프로그램 간 통신과 데이터 구조를 맞추어 하나의 통합 시스템으로 구성했습니다.

# 🏗 전체 시스템 구성

![전체 시스템 구성도](docs/images/system-architecture.png)

전체 시스템은 기능에 따라 **4개의 프로그램**으로 구성했습니다.

```text
Sushi Store Management System
│
├── ⚙️ 관리자 프로그램
│   ├── TCP Server
│   ├── 실시간 주문 관리
│   ├── 테이블 현황
│   ├── 메뉴 관리
│   ├── 회원 / 포인트 관리
│   ├── 재고 관리
│   └── 매출 관리
│
├── 🖥 키오스크 프로그램
│   ├── 메뉴 조회
│   ├── 주문
│   ├── 회원 / 포인트
│   └── 결제
│
├── 📱 모바일 앱
│   ├── 회원가입 / 로그인
│   ├── 메뉴 조회
│   ├── 모바일 주문
│   └── 주문 상태 조회
│
└── ⏳ 웨이팅 프로그램
    ├── 대기 등록
    ├── 대기 순번 관리
    ├── 테이블 상태 확인
    └── SMS 입장 안내
```

# 🧩 프로그램 구성

## ⚙️ 관리자 프로그램

키오스크와 모바일 앱에서 발생한 주문을 처리하고  
매장 운영에 필요한 데이터를 통합 관리합니다.

또한 TCP 서버 역할을 수행하여  
키오스크와 앱의 요청을 처리합니다.

### 주요 기능

- TCP Server
- 실시간 주문 관리
- 앱 주문 접수 및 상태 관리
- 테이블 현황 관리
- 메뉴 관리
- 과거 주문 및 영수증 조회
- 회원 및 포인트 관리
- 재고 관리
- 매출 리포트
- CSV 기반 데이터 관리

➡️ **[`admin` 브랜치에서 코드 및 상세 README 보기](../../tree/admin)**

# 🔗 프로그램 연동

## 키오스크 ↔ 관리자

키오스크는 관리자 TCP 서버와 통신하여  
메뉴 및 회원정보를 조회하고 주문·결제 정보를 전달합니다.

```text
Kiosk
  │
  │ TCP/IP + JSON
  ▼
Admin TCP Server
```

대표적인 요청:

```text
GET_MENU
GET_MEMBER
NEW_ORDER
PAYMENT_COMPLETE
```

---

## 앱 ↔ 관리자

모바일 앱 역시 관리자 TCP 서버와 통신하며  
회원, 메뉴, 주문 관련 기능을 처리합니다.

```text
App
 │
 │ TCP/IP + JSON
 ▼
Admin TCP Server
```

대표적인 요청:

```text
REGISTER_MEMBER
LOGIN_MEMBER
GET_MENU
NEW_APP_ORDER
GET_ORDER_STATUS
```

---

## 웨이팅 연동

웨이팅 프로그램은 매장의 테이블 상태를 확인하여  
대기 고객의 입장 순서를 관리합니다.

입장 안내가 필요한 경우 **SOLAPI SMS API**를 이용하여  
대기 고객에게 안내 문자를 전송합니다.

# 💾 데이터 관리

관리자 프로그램에서는 주문 및 매장 운영 데이터를  
CSV 파일 기반으로 관리했습니다.

```text
CSV
│
├── 진행 중 주문
├── 완료 주문 / 매출
├── 주문 상세
├── 앱 결제 임시정보
├── 주문 거절 기록
├── 메뉴
├── 회원 / 포인트
└── 재고 기본정보
```

세부적인 CSV 구조와 주문 처리 방식은  
[`admin` 브랜치 README](../../tree/admin)에서 확인할 수 있습니다.

# 👥 팀 구성 및 역할

본 프로젝트는 **5인 팀 프로젝트**로 진행했습니다.

| 이름 | 역할 | 주요 담당 |
|---|---|---|
| 홍석민 | 팀장 | 프로젝트 설계, 코드 통합, 데이터 구조 및 통신 시스템 설계 |
| 조시현 | 부팀장 | 관리자 프로그램, TCP 서버, 주문 처리, 회원·포인트·매출 처리 |
| 김승환 | 팀원 | 키오스크 일부 기능, 웨이팅 프로그램, SOLAPI SMS 연동 |
| 노원종 | 팀원 | 모바일 앱 구현 및 관리자 서버 연동 |
| 함동윤 | 팀원 | 키오스크 일부 기능, 다국어 처리 및 웨이팅 구조 설계 |

각 담당자는 맡은 프로그램과 기능을 구현하면서  
공통 데이터 구조와 통신 규격을 맞추어 전체 시스템을 연동했습니다.
